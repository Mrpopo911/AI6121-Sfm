# AI6121 - Structure from Motion

Group project for AI6121: Structure from Motion at Nanyang Technological University (NTU).

## Project

The goal of this project is to reconstruct 3D structures from multi-view 2D images or video frames using Structure-from-Motion (SfM).

Our initial work focuses on developing and validating a baseline SfM pipeline before exploring potential extensions.

## Dataset

The project uses multi-view images captured using a smartphone camera.
